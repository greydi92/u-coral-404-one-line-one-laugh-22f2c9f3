# One Line, One Laugh

Built for the [make.fun "One Line, One Laugh" bounty](https://make.fun/bounty/u-coral-404-one-line-one-laugh-22f2c9f3) — a program that writes exactly one funny line to `/output/entry.txt`. Join make.fun with referral code `qgn48q27`: https://make.fun/r/qgn48q27

> My therapist ghosted me. Even my abandonment issues feel abandoned.

## Run

```sh
node main.ts
```

`main.ts` writes the line above to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with no trailing newline, no network, and exits 0.
